# Infrastructure

This folder is reserved for containerized developer environments and deployment resources.

## Planned contents

- Dockerfiles for server and client
- Docker Compose setup for local orchestration
- Nginx configuration
- Optional database and reverse proxy services

## Suggested local stack

- API/service backend
- PostgreSQL
- Redis
- Nginx
- Web client

## Example local flow

```text
docker compose up
```

This should start the environment needed for local development and testing of the CloudOS prototype.
